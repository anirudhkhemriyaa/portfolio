# Modern Terminal Portfolio

A premium, recruiter-friendly developer portfolio with a terminal aesthetic.

## Tech Stack
- **Frontend**: React, Vite, Tailwind CSS v4, Framer Motion, Lucide Icons
- **Backend**: Python FastAPI, Pydantic
- **Deployment**: Vercel (Frontend), Railway/Render (Backend)

## Project Structure
- `frontend/`: React application with Tailwind v4.
- `backend/`: FastAPI server for contact form and dynamic data.

## Identity
- **UI**: Modern Black (#0A0A0A)
- **Accent**: Muted Cyan (#7DD3FC)
- **Typography**: Geist Mono / JetBrains Mono

## Getting Started

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
pip install -r requirements.txt
python main.py
```

## Features
- Optional Terminal Interface (sticky bottom right)
- Expandable technical project details
- Tree-structure skills visualization
- Premium glassmorphism UI
- Responsive and fast
